 

This project focuses on analyzing BlinkIt sales data and creating an interactive Power BI dashboard to understand sales performance, customer behavior, and business trends. The dashboard provides meaningful insights through data visualization and helps in making data-driven decisions.

## Data Cleaning & Preparation

* Cleaned and transformed raw BlinkIt sales data using Excel.
* Removed duplicate records and handled missing values.
* Standardized data formats to improve data quality.
* Prepared the dataset for effective analysis and visualization.

## Dashboard Features

* Key Performance Indicators (KPIs) for overall sales performance.
* Analysis of sales by product categories.
* Customer insights based on different segments.
* Visual representation of sales trends.
* Interactive filters and slicers for better data exploration.

## Tools & Technologies Used

* **Power BI** – Dashboard development and data visualization
* **Microsoft Excel** – Data cleaning and preprocessing

## Key Insights

* Identified sales trends and patterns from the dataset.
* Analyzed product category performance.
* Explored customer-related metrics to understand business performance.
